# Freelance Marketplace

## Project Description
A console-based Freelance Marketplace built using Python.

## Features
- Client Registration and Login
- Freelancer Registration and Login
- Project Posting
- Bid Application
- Freelancer Hiring
- Project Status Tracking
- Ratings and Reviews
- Admin Dashboard
- File Handling using Pickle

## Technologies Used
- Python
- Dictionary
- Functions
- File Handling
- Pickle Module

## Roles
### Client
- Post Projects
- View Bids
- Hire Freelancers
- Track Project Status
- Give Reviews

### Freelancer
- View Projects
- Apply Bids
- Update Project Status
- View Reviews

### Admin
- View Clients
- View Freelancers
- View Projects
- View Bids
- View Hired Projects
- View Reviews

python main.py
