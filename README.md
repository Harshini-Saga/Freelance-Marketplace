# Freelance Marketplace

## Project Overview
Freelance Marketplace is a console-based application developed using Python and MySQL. The system connects clients and freelancers on a single platform where clients can post projects and freelancers can place bids. Clients can review bids and hire suitable freelancers for their projects.

## Features

### Client Module
- Client Registration and Login
- Post New Projects
- View Posted Projects
- View Bids on Projects
- Hire Freelancers
- Give Ratings and Reviews

### Freelancer Module
- Freelancer Registration and Login
- View Available Projects
- Place Bids on Projects
- View Hired Projects
- Check Ratings and Reviews

### Admin Module
- Admin Login
- View Clients
- View Freelancers
- Monitor Projects and Bids

## Technologies Used

- Python
- MySQL
- SQL Queries
- Git & GitHub

## Database Tables

- clients
- freelancers
- projects
- bids
- hired_projects
- reviews

## Project Workflow

1. Client registers and logs in.
2. Client posts a project.
3. Freelancers view projects and place bids.
4. Client reviews bids and hires a freelancer.
5. Freelancer completes the project.
6. Client provides ratings and reviews.

## Installation

1. Clone the repository

```bash
git clone https://github.com/Harshini-Saga/Freelance-Marketplace.git
```

2. Navigate to the project folder

```bash
cd Freelance-Marketplace
```

3. Install MySQL and create the required database.

4. Update database credentials in `db.py`.

5. Run the application

```bash
python main.py
```
